# 🌤️ AI-Powered Weather Forecast App

An AI-powered weather forecasting web application built using React, Vite, and OpenWeather API.

## 🚀 Features

- 🌍 Search weather by city
- 🌡️ Real-time temperature
- 💧 Humidity
- 💨 Wind Speed
- 👁️ Visibility
- 🌤️ Weather Icons
- 📱 Responsive UI
- 🌙 Dark Theme
- 🤖 AI-based Weather Design

## 🛠️ Technologies Used

- React.js
- Vite
- JavaScript
- HTML5
- CSS3
- OpenWeather API
